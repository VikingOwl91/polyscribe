## [0.1.0] - 2025-08-13

### Added
- Initial release of PolyScribe.
- Transcription functionality for audio and video files.
- Merging of JSON transcripts.
- Interactive model downloader and updater.
- GPU backend selection (CUDA, ROCm/HIP, Vulkan).
- Plugin system with a stub plugin for `tubescribe`.
